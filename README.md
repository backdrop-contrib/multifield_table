Multifield table
================

Multifield table provides a simple formatter that displays Multifield subfields
in a table.

You only have to choose which subfields you want to display and their order in
the Multifield manage display tab and choose Table formatter for your
Multifield subfields in your entity type manage display tab. Then, Multifield
table displays the multifields item in a nice table.

Multifield table also provides a new Widget for Multifield items, allowing
content editors to create and edit Multifield items easily.

Requirements
------------

This module requires that the following modules are also enabled:

 * [Multifield](https://github.com/backdrop-contrib/multifield)

Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.
